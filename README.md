# University Materials Website Frontend

A simple Angular frontend project for organizing and accessing university study materials.

## Overview
This project provides a clean web interface for students to navigate study resources and important university links. It includes a basic layout with a navbar, footer, and multiple pages such as Home, About, and Tools.

The website also contains quick links to useful external resources like:
- Student Portal
- Course Schedule / Materials Page
- University Calendar

## Features
- Simple and responsive Angular layout
- Navigation between pages using Angular Router
- Reusable shared components such as Navbar and Footer
- External quick links for important university resources
- Clean project structure for future expansion

## Technologies Used
- Angular 14
- TypeScript
- HTML
- SCSS
- Bootstrap 5
- Font Awesome

## Project Structure
- `src/app/pages` → application pages such as Home, About, and Tools
- `src/app/shared` → reusable UI components like Navbar and Footer
- `src/app/layout` → main shell layout
- `app-routing.module.ts` → application routing configuration

## Notes
- This project is currently a simple frontend structure and can be extended with more pages and dynamic content.
- Some links in the navbar point to external university resources.
